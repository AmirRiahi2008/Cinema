# دو صندلی — Two Seats

سینمای خصوصی دونفره برای امیر؛ یک اتاق، یک فیلم و حرف‌های بین سکانس‌ها.

## انتشار روی Vercel

برای انتشار رابط روی Vercel، راهنمای README-VERCEL.md را بخوان. مسیر `pnpm build:vercel` و فایل `vercel.json` آماده شده‌اند؛ بک‌اند و فیلم‌ها روی سرور Cloudflare فعلی می‌مانند.

## استفاده از نسخهٔ آنلاین

1. اسم خودت، اسم اتاق و حال‌وهوای امشب را انتخاب کن.
2. «دعوت پارتنرم» را بزن و لینک یک‌بارمصرف را برای پارتنرت بفرست.
3. مهمان با وارد کردن اسمش، صندلی دوم را می‌گیرد. نفر سوم پذیرفته نمی‌شود.
4. فایل فیلم را آپلود کن یا لینک YouTube، Aparat، MP4، WebM یا HLS بده.
5. هر دو «من آماده‌ام» را بزنید؛ «شروع با هم» یک شمارش معکوس سه‌ثانیه‌ای دارد.
6. با هم فیلم ببینید، چت کنید و واکنش بفرستید. صدای هر دستگاه مستقل است.

برای ورود دوباره، از همان مرورگر استفاده کنید؛ کلید اتاق روی همان مرورگر ذخیره می‌شود. مهمان نمی‌تواند جایگاه میزبان را بگیرد. میزبان می‌تواند از تنظیمات، صندلی مهمان را آزاد و دعوت تازه صادر کند. برای خروج موقت، «بیرون رفتن از سینما» را بزنید؛ حذف کامل اتاق و فایل‌ها از تنظیمات انجام می‌شود.

## قابلیت‌ها

- رابط فارسی و راست‌به‌چپ، سازگار با موبایل، تم گرم/رمانتیک/شب آرام و حالت سینما.
- دو جایگاه ثابت، دعوت یک‌بارمصرف، نگهداری فقط هش کلیدهای دسترسی روی سرور.
- همگام‌سازی پلی، توقف، جابه‌جایی زمان و سرعت پخش، با زمان سرور و شمارهٔ نسخه برای جلوگیری از تداخل فرمان‌ها.
- اصلاح اختلاف زمان به‌صورت خودکار؛ دریافت وضعیت هر یک ثانیه در صفحهٔ فعال و اتصال مجدد با فاصلهٔ افزایشی.
- چت ذخیره‌شده با آخرین ۵۰۰ پیام، نشانگر نوشتن، وضعیت حضور، واکنش ایموجی و ارسال مجدد بدون پیام تکراری.
- آپلود فیلم تا ۴ GiB در بخش‌های ۸ MiB، دو بخش هم‌زمان، سه تلاش برای هر بخش و ادامهٔ بخش‌های کامل پس از انتخاب دوبارهٔ همان فایل.
- آپلودهای نیمه‌تمام از پنجرهٔ انتخاب فیلم قابل لغو هستند.
- پخش فایل اصلی از R2 با استریم و درخواست Range؛ سرور فیلم را دوباره فشرده یا تبدیل نمی‌کند.
- انتخاب کیفیت برای HLS و منابع مستقیم آپارات در صورت موجود بودن کیفیت‌های مختلف.
- زیرنویس SRT/VTT تا یک MiB؛ تبدیل SRT به VTT و نمایش مشترک برای دو نفر.
- پخش تمام‌صفحه، تصویر در تصویر برای فایل‌های سازگار، حجم صدا و بی‌صدا کردن مستقل.
- صفحهٔ راهنما، پیام‌های خطای روشن، حذف فیلم/اتاق با تأیید داخل برنامه و امکان امتحان با انیمیشن رایگان.

## پشتیبانی واقعی از منابع

| منبع | پخش | همگام‌سازی | نکته |
| --- | --- | --- | --- |
| MP4 با H.264/AAC | بله | بله | بهترین سازگاری میان مرورگرهای گوشی و لپ‌تاپ |
| WebM | در مرورگرهای سازگار | بله | پشتیبانی به مرورگر/کدک بستگی دارد |
| فایل با کیفیت 4K | در صورت پشتیبانی دستگاه و اینترنت | بله | کیفیت اصلی نگه داشته می‌شود؛ امکان تبدیل سروری وجود ندارد |
| MOV، MKV، HEVC | وابسته به کدک و مرورگر | در صورت امکان پخش | پخش همهٔ این فایل‌ها روی همهٔ دستگاه‌ها تضمین نمی‌شود |
| لینک مستقیم MP4/WebM | بله، اگر لینک معتبر و قابل دسترسی باشد | بله | آدرس باید فایل ویدیو باشد، نه یک صفحهٔ وب |
| HLS / m3u8 | با پشتیبانی بومی یا HLS.js | بله | CORS منابع باید اجازهٔ دریافت بدهد؛ پخش زنده برای این برنامه طراحی نشده است |
| YouTube | پلیر رسمی IFrame API | بله | نیاز به API Key ندارد؛ دسترسی شبکه و اجازهٔ Embed لازم است؛ کیفیت در پلیر انتخاب می‌شود |
| Aparat | ابتدا منابع عمومی و سپس پلیر رسمی | منابع مستقیم: بله؛ Embed: محدود | API عمومی آپارات ممکن است تغییر کند یا دسترسی مستقیم ندهد؛ حالت جایگزین به‌وضوح نمایش داده می‌شود |

ویدیوهای محافظت‌شده با DRM، سایت‌های اشتراکی مثل Netflix و صفحهٔ معمولی سایت‌های فیلم به‌عنوان لینک مستقیم پشتیبانی نمی‌شوند. صدای مهمان ممکن است طبق سیاست مرورگر ابتدا به یک لمس برای فعال شدن نیاز داشته باشد.

## فناوری

React 19 + TypeScript، Vinext با قراردادهای Next.js، Cloudflare Workers، D1 برای اطلاعات اتاق و چت، R2 برای فیلم و زیرنویس، HLS.js و YouTube IFrame API. همهٔ کتابخانه‌های برنامه رایگان‌اند و این پروژه سرویس اشتراکی شخص ثالث یا API Key لازم ندارد.

D1 و R2 اطلاعات را برای دستگاه‌های مختلف مشترک نگه می‌دارند. localStorage تنها برای کلید ورود هر مرورگر و مشخصات آپلود قابل ادامه به کار می‌رود. برای پخش داخل محیط‌هایی که کوکی شخص ثالث را مسدود می‌کنند، یک امضای HMAC با زمان انقضا تنها دسترسی خواندن به رسانهٔ همان اتاق می‌دهد؛ این امضا هیچ دسترسی نوشتن یا مدیریت اتاق ندارد. آزاد کردن صندلی، امضای قبلی مهمان را هم باطل می‌کند.

## اجرای محلی در macOS، Windows یا Linux

Node.js نسخهٔ 22.13 یا بالاتر، Git و pnpm نسخهٔ 11.25 لازم است. اجرای محلی نیازی به حساب Cloudflare ندارد؛ D1 و R2 با Miniflare شبیه‌سازی می‌شوند.

```bash
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm build
```

بعد از اولین Build، پایگاه دادهٔ محلی را آماده کن:

```bash
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_salty_thunderbird.sql
```

سپس:

```bash
pnpm dev
```

آدرس Local چاپ‌شده توسط سرور را باز کن. برای آزمایش دو جایگاه، پنجرهٔ عادی و پنجرهٔ Incognito را روی همان آدرس استفاده کن. لینک localhost فقط برای آزمایش روی همان دستگاه مناسب است؛ برای اتصال واقعی پارتنر از نسخهٔ منتشرشده استفاده کن.

پیش‌نمایش نسخهٔ Buildشده:

```bash
pnpm start
```

مهاجرت فقط یک‌بار روی هر پایگاه دادهٔ محلی خالی اجرا می‌شود. بعد از تغییرات بعدی در schema، با `pnpm db:generate` مهاجرت تازه بساز و فقط مهاجرت‌های جدید را اعمال کن. پایگاه دادهٔ محلی، جدا از پایگاه دادهٔ آنلاین است.

## تست‌ها

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm test:built
```

تست‌های یکپارچه در Worker واقعی شبیه‌سازی‌شده با D1 و R2 اجرا می‌شوند؛ موارد شامل رقابت برای صندلی دوم، نبود دسترسی مهمان به عملیات میزبان، دعوت یک‌بارمصرف و لغو آن، استقلال اتاق‌ها، پیام تکراری، زمان و نسخهٔ پخش، آپلود چندبخشی و ادامه، Range/HEAD، زیرنویس و حذف واقعی فایل‌ها هستند. تست نسخهٔ Buildشده، همان مسیرهای API و HTML فارسی را بررسی می‌کند.

پاسخ API آپارات در تست‌ها به‌صورت fixture کنترل‌شده است. این تست‌ها دسترسی زنده به یوتیوب/آپارات یا پخش واقعی روی دو دستگاه را اثبات نمی‌کنند. این محیط ابزار کنترل مرورگر نداشت؛ مشاهدهٔ ظاهری و تست پلیر روی مرورگر واقعی انجام نشده است.

## انتشار مستقل روی Cloudflare (اختیاری)

نسخهٔ آمادهٔ این پروژه با Sites منتشر می‌شود. اگر خواستی زیر حساب Cloudflare خودت میزبانی کنی، D1 و R2 بساز، شناسه‌ها را در یک کپی از `wrangler.example.jsonc` قرار بده، و با Wrangler مهاجرت و انتشار را انجام بده:

```bash
pnpm exec wrangler login
pnpm exec wrangler d1 create two-seats
pnpm exec wrangler r2 bucket create two-seats-media
```

فایل نمونه را به `wrangler.self-host.jsonc` کپی کن و `database_id` را با مقدار واقعی خروجی دستور قبلی عوض کن. هیچ شناسهٔ نمونه را به‌عنوان شناسهٔ واقعی استفاده نکن. سپس:

```bash
pnpm build
pnpm exec wrangler d1 execute DB --remote --config wrangler.self-host.jsonc --file drizzle/0000_salty_thunderbird.sql
pnpm exec wrangler deploy --config wrangler.self-host.jsonc
```

فایل خودمیزبانی و هر اطلاعات محلی در Git نادیده گرفته می‌شوند. برای نسخهٔ Sites، ابزار انتشار پروژه مهاجرت‌ها و Bindingها را مدیریت می‌کند و به فایل نمونهٔ Wrangler نیازی نیست.

فضای کل فیلم‌های این نصب عمداً به ۸ GiB محدود شده است و رزروهای آپلود نیز در این سقف حساب می‌شوند. پلن‌های رایگان منابع و درخواست‌ها سقف دارند؛ رایگان بودن مصرف نامحدود نیست. R2 Standard در زمان ساخت این پروژه سهمیهٔ ۱۰ GB-month رایگان و خروجی اینترنت رایگان دارد. جزئیات فعلی را در مستندات رسمی بررسی کن:

- https://developers.cloudflare.com/r2/pricing/
- https://developers.cloudflare.com/workers/platform/pricing/
- https://developers.cloudflare.com/d1/platform/pricing/
